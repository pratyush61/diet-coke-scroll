# Diet Coke | Animated Can Scroll

A scroll-driven product page built with GSAP ScrollTrigger. The can is inline SVG, so there are no image files to manage.

Unofficial fan design demo. Diet Coke and Coca-Cola are trademarks of The Coca-Cola Company.

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Files
- `index.html` structure and inline SVG can
- `style.css` silver and red design system
- `main.js` GSAP ScrollTrigger animation
