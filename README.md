## ✨ Overview

Diet Coke Animated Can Scroll is a creative frontend project exploring modern product presentation through animation, visual storytelling, and responsive web design.

The project uses a custom inline SVG illustration of a Diet Coke can, animated with GSAP and ScrollTrigger.

This is an unofficial fan-made design demonstration. Diet Coke and Coca-Cola are trademarks of The Coca-Cola Company.

## 🚀 Features

- Custom inline SVG Diet Coke can.
- GSAP-powered entrance animations.
- ScrollTrigger-based product storytelling.
- Responsive navigation with mobile menu.
- Modern silver-and-red visual design.
- Interactive call-to-action elements.
- Responsive layouts for different screen sizes.
- Reduced-motion CSS support.

## 💻 Getting Started

### Prerequisites

- Modern web browser
- Node.js and npm (optional, for local development server)

### Installation

Clone the repository:

```bash
git clone https://github.com/pratyush61/diet-coke-scroll.git
```

Navigate into the project:

```bash
cd diet-coke-scroll
```

### Run Locally

Open `index.html` directly in your browser.

Alternatively, start a local development server:

```bash
npx serve .
```

Open the local URL displayed in your terminal.
